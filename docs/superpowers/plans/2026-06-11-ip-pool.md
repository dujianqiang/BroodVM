# IP 池 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 桥接模式 VM 创建时从配置的 IP 池自动分配静态 IP，通过 cloud-init 写入 network-config，彻底解决桥接 VM 无 IP 的问题。

**Architecture:** 在 `config.yaml` 的 `host.ip_pool` 中配置 IP 列表、共用网关和 DNS。`VMService.Create()` 对桥接且未指定 IP 的请求，加锁扫描 DB 找出第一个未被非 deleted VM 占用的池 IP，写入 VM 记录后再释放锁，保证并发安全。VM 删除后 status 变为 `deleted`，其 IP 自动从"已用集合"中消失，可被复用。

**Tech Stack:** Go 标准库 `sync.Mutex`，现有 `config/config.go`、`service/vm.go`、`store/vm.go`，无新依赖。

		t.Fatalf("Create vm-b1: %v", err)

		Name: "vm-b2", VCPU: 1, MemoryGB: 1, DiskGB: 10, NetworkType: "bridge",
	})
	if err != nil {
		t.Fatalf("Create vm-b2: %v", err)
	}

	if req.NetworkType == "bridge" && req.IP == "" {
		if len(s.cfg.Host.IPPool.IPs) > 0 {
			ip, err := s.findFreePoolIP()
			if err != nil {
				s.mu.Unlock()
				return "", err
			}
			req.IP = ip
			req.Gateway = s.cfg.Host.IPPool.Gateway
			if req.DNS == "" {

			}

**3d. 在文件末尾（`GetTask` 之前）新增 `findFreePoolIP()`：**

```go
// findFreePoolIP 在 s.mu 持有期间调用，返回池中第一个未被活跃 VM 占用的 IP。
func (s *VMService) findFreePoolIP() (string, error) {
	vms, err := s.vmStore.List()
	if err != nil {
		return "", err
	}
	used := make(map[string]bool, len(vms))
	for _, vm := range vms {
		if vm.IP != "" {
			used[vm.IP] = true
		}
	}
	for _, ip := range s.cfg.Host.IPPool.IPs {
		if !used[ip] {
			return ip, nil
		}
	}
	return "", fmt.Errorf("IP 池已耗尽，请扩充配置")
}
```
